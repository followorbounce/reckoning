# Reckoning

An interactive handbook of measure, shape, number, sky, weather, signal, ship and the code of life: exact unit definitions with sources, checked formulas for 42 figures and solids, symbols and a working slide rule, a globe and great-circle sailings, the kinds of time, the celestial sphere and planets, code flags, Morse and the Beaufort scale, a ship's structure, load lines and a stability simulator, DNA bases, the IUPAC letters, the double helix and supercoiling, plus a three-language glossary.

Live: https://followorbounce.github.io/reckoning/

Build: `python3 build.py` (runs the checks in tests/ first; needs Python 3 and Node.js).
