# Reckoning

An interactive handbook of measure, shape, number, sky, weather and signal: exact unit definitions with sources, checked formulas for 42 figures and solids, symbols and a working slide rule, a globe and great-circle sailings, the kinds of time, the celestial sphere and planets, code flags, Morse and the Beaufort scale.

Live: https://followorbounce.github.io/reckoning/

Build: `python3 build.py` (runs the checks in tests/ first; needs Python 3 and Node.js).
