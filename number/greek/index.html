Greek alphabet

Science ran out of Latin letters long ago. The Greek alphabet supplies the second set, and many letters have settled meanings: λ is a wavelength, ρ a density, Ω the ohm. In astronomy α, δ give a star’s place on the sky and λ, β its place along the ecliptic.

Character names: The Unicode Standard: code charts and character names (Mathematical Operators, Greek, Miscellaneous Symbols). Unicode spells λ “lamda”, a spelling also used in modern Greek.

Look-alikes

Some symbols have their own Unicode characters that look exactly like Greek letters. Text that mixes them searches and sorts badly, so the standard asks for the plain letter.

CharacterUse insteadNote
µU+00B5 micro signμU+03BC greek small letter muThe micro sign is kept only for compatibility with old character sets; Unicode maps it to the Greek small mu. Either way the prefix is printed upright: μm, not 𝜇m.

How letters are set

A letter that stands for a quantity is italic: λ = 500 nm. A unit or prefix symbol is upright: μm, Ω. Writing μm in italics turns the prefix into a quantity, so the rule matters. Sources: BIPM SI Brochure, ISO 80000-2.
