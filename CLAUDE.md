# Reckoning

Interactive handbook (measure, shape, number, sky & sea, weather, signal, ship, code of life, light),
built in five waves (all live since 2026-10-14; Light is wave 5), plus a glossary and a naming page. Static site generated by `python3 build.py`; GitHub Pages from `main` at
https://followorbounce.github.io/reckoning/ . Never hand-edit generated HTML (index.html,
measure/, shape/, about/, sitemap.xml, robots.txt).

## Rules
- **Never name the scanned source books** anywhere in the project (code, docs, commits, pages).
  They live in /home/none/git/_todo (image.pdf, image-2.pdf, image-3.pdf) and are a syllabus only.
  Cite only primary standards (data/sources.py). All text and drawings are original.
- English only. iPhone rules: safe areas, 44px targets, 16px inputs.
- Old values are kept as "then and now", never silently replaced.
- The build runs every tests/check_*.py first and stops on any failure; after writing the pages it checks that
  every internal href/src resolves (check_links) and stops if not
  (`--skip-checks` only for quick layout iterations; never publish from it).

## Data (single source of truth)
- data/units.py: every unit as an exact Fraction of its SI unit (`f`), `exact`, `status`,
  `by` (definition text), `src` (key in data/sources.py). Temperature uses TEMP_OFFSET.
- data/si.py: defining constants, base units, 22 derived units, 24 prefixes.
- data/shapes.py: 42 shapes. Formula strings are valid Python AND JavaScript (use `**`, `sqrt`,
  `PI`, `rad(deg)`); the same strings are checked by tests and evaluated live by assets/shape.js.
  VALID holds parameter conditions (Python `and`/`or`, converted for JS).
- data/texts.py: Measure page text.
- data/signals.py: ICS flags (designs as kinds + colour letters, checked against the blazons),
  single-letter meanings, pennants, substitutes; Morse (ITU-R M.1677-1); ICAO/ITU and 1941
  alphabets; COLREGs sound signals. flagart.py draws flags and WMO weather symbols as SVG.
- data/weather.py: Beaufort (Met Office/WMO limits and wave heights), WMO code 3700, visibility
  terms, Saffir-Simpson (NHC, km/h as published), cyclone basins. data/land-110m.json is Natural
  Earth (public domain) for the basin map; rooms2.py builds the Signal and Weather pages.
- data/number.py: 59 symbols (Unicode name + Cajori first use, blank when unverified), constants, Greek
  alphabet with uses, Unicode look-alikes (micro/ohm/ångström/increment), 32 compass points.
- data/sky.py: planets (symbol, Unicode name, gods, naming, IAU 1989 abbreviations), NASA fact-sheet values,
  aspects, the 88 constellations, 12 signs, ports and preset routes, zone letters.
- data/constbounds_1875.dat: Roman (1987) / CDS VI/42 constellation table (equinox 1875), used as is.
- rooms3.py builds the Number and Sky & sea pages; writes assets/land.json (Natural Earth rings) for
  the globe and the sailing charts. Exact trig values are read from assets/trigmath.js via node.

- data/ship.py: 25 named hull parts (midship section, rooms4.midship_svg) and the Load Line Convention 1966
  mark sizes/rules. data/life.py: IUPAC letter names (the SETS live only in assets/dnamath.js), bases with
  ring graphs (STRUCT/RING/HBONDS, drawn by rooms4.base_svg), A/B/Z helix parameters. data/glossary.py: 61
  terms EN/ES/FR + SAME_WORD. data/names.py: gods, moon themes, dwarf planets, weekdays, months, elements.
- rooms4.py builds Ship, Code of life, /glossary/ and /sky/names/. build.py also writes
  assets/signal-of-day.json (26 code flags as SVG + meanings + Morse), read at run time by the
  "Signal of the day" card on followorbounce.github.io (engine/signal-of-day.* there) - keep its shape stable.

- rooms5.py builds the Light room (light/: hub, refraction, lenses, prism, mirrors, rainbow, bench). Numbers in its text are
  computed at build time by running assets/optics.js through node (values()), never typed in.

## Checks
- tests/check_wave5.py: every material source key exists; then tests/check_wave5.js (123 checks) on assets/optics.js: N-BK7/N-F2 n_d, n_F, n_C and
  Abbe numbers vs the SCHOTT catalogue, fused silica vs Malitson, water vs the handbook n_D (relative to air) and vs the IAPWS 1997
  formula (written out in the test), diamond n_D; Fresnel at 0°, Brewster (R_p = 0, rays at 90°), grazing; slab (Snell, parallel exit,
  lateral shift); half-cylinder TIR either side of the critical angle; prism traced deviation = i + e − A, scanned minimum = closed form,
  n from δ_min; five lens forms: traced paraxial back focus = thick-lens formula = ABCD matrices; spherical and chromatic aberration
  signs; ideal lens images every ray to 1/u + 1/v = 1/f; parabola focuses all parallel rays (< 1e-9 mm); sphere crosses at R/(2 cos α);
  convex virtual focus; plane mirror; rainbow: Descartes minimum = scan = tracer (one internal reflection), 42° / 51°; energy sums to 1.
- tests/check_wave3.py: Unicode names of every symbol/letter/planet/sign; look-alike normalisation; 88
  constellations vs the boundary table; then runs tests/check_wave3.js, which tests assets/astro.js,
  navmath.js and trigmath.js against published worked examples (Meeus 7, 12.a/b, 25.a, 28.b, 32.a;
  Roman's 8 test positions; GDA Vincenty example on GRS80; WGS 84 meridian quadrant), plus internal
  cross-checks (JPL Earth vs NOAA Sun < 0.02°, haversine vs n-vector, rhumb vs integration, triangle
  solver round trips and SSA counts, slide-rule products). Node is a build dependency.
- tests/check_wave4.py: load-line sizes vs the Convention text; 35 ft³ per long ton; every part drawn; IUPAC
  names = sets; base formulas recomputed from the drawn ring graphs by valence; helix twist = 360/bp and
  pitch = rise x bp; glossary/names sanity; then tests/check_wave4.js on assets/stability.js and dnamath.js:
  box KB/BM, GZ = wall-sided formula to deck-edge immersion, circular section GZ = (KM-KG) sin θ, angle of loll,
  GZ antisymmetry, constant displaced area, free-surface shift = b³/12, FWA = T/40, IMO A 2.2 limits; IUPAC
  complements; Hopf link Lk = 1; Tw + Wr = Lk = Gauss linking of the ribbon edges (Călugăreanu-White-Fuller)
  for interwound and toroidal coils; handedness signs.
- tests/check_units.py: factors vs reference values typed separately from NIST tables;
  temperature fixed points; prefix/SI table sizes; every source key exists.
- tests/check_wave2.py: flags A-Z = ICAO words, designs draw, Morse codes distinct, PARIS = 50
  units, Beaufort ranges contiguous and consistent with 0.836 B^1.5, sea state, Saffir-Simpson.
- tests/check_shapes.py: every area/volume formula vs Monte Carlo of a point-membership test
  written from the shape's definition (not its formula); selected perimeters/surfaces by
  numerical integration; Euler characteristic from meshes and V-E+F.

## Front end
- assets/audio.js (shared, iOS unlock), morse.js, horn.js, hoist.js, sea.js (Beaufort canvas).
- assets/convert.js: exact BigInt rational conversion; prints full decimals when they terminate.
- assets/shape.js: sliders, live quantities, 2D SVG figures. assets/solid.js: three.js r128
  solids (lathe for solids of revolution; cut-away quarter for hollow solids; `RK_RENDER()` hook
  for headless capture). KaTeX 0.16.9 from cdnjs renders formulas.
- Wave 3 front end: astro.js, navmath.js, trigmath.js are pure (UMD: window.RK_* or module.exports)
  so node tests run the page code. UI: trig.js, sliderule.js, globe.js, sailing.js, skytime.js,
  celestial.js, orrery.js. Globe and celestial sphere expose RK_RENDER for headless capture.
- Wave 4 front end: stability.js and dnamath.js are pure (UMD). UI: hull.js (tap parts; framing toggle),
  loadline.js, stab-ui.js, iupac.js, helix.js and supercoil.js (three.js, RK_RENDER hooks).
- Light front end: optics.js is pure (UMD, RK_OPTICS): Sellmeier materials (water is absolute, divided by air from Peck & Reeder so all
  indices are relative to air, like glass catalogues; air itself is n = 1 on the bench), exact 2D tracer with Fresnel branching (minI
  threshold), shapes (lens from signed R1/R2/tc/D, prism, slab, half-cylinder, drop, mirrors, ideal thin lens). light.js is the 2D-canvas
  bench, one setup per page via data-page; window.RK_RENDER() renders synchronously (use it for headless screenshots: 2D canvas captures
  fine once rendered before load). The bench is always a dark table in both themes; white light = 12 wavelengths.
- Headless Firefox screenshots don't capture WebGL: inject `RK_RENDER()` then copy the canvas
  via toDataURL into an <img> in a throwaway _dbg_*.html (delete after). Use a fresh --profile.
